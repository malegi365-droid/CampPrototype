# Ability Weaving

Ability Weaving is the core combat mechanic of Camp: Prototype.

Players may activate an ability, switch classes, and use another ability before the first expires.

Certain ability sequences create named Weaves.

A successful Weave grants:

- Unique gameplay effect
- Special VFX
- Screen pulse
- Audio cue ("Weave")
- Named technique popup

Future support:

- Double Weaves
- Triple Weaves
- Weave Codex
- Unlockable Weaves
