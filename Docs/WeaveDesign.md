# Ability Weave Design

## Philosophy

Ability Weaving rewards players for combining class abilities in meaningful ways.

A successful Weave should:

- Feel powerful.
- Change gameplay.
- Be visually recognizable.
- Be easy to understand.
- Encourage experimentation.
